How to get these credentials?

🔑 Prerequisites: Required Roles

  • Google Workspace Super Admin – required to authorize domain-wide delegation.
  • Google Cloud Project Owner/Editor – required to create the project, enable APIs, and manage service accounts.

⚙️ Step 1: Set Up Your Google Cloud Project

Create a New Project

  • Go to the Google Cloud Console.
  • From the welcome screen, click New Project.
  • In the "New Project" window, enter a project name (e.g., `gws-security-dashboard`).
  • Click Browse and select your organization. This is a critical step.
  • Click Create.

Enable Required APIs

  • From the main menu (☰), go to APIs & Services → Library.
  • Search for and enable the following APIs: Admin SDK API, Gmail API, Alert Center API, and (optionally) BigQuery API.

🗝️ Step 2: Create the Service Account & Get Your Credentials

Create the Service Account

  • Go to IAM & Admin → Service Accounts → Create Service Account.
  • Enter a name and description.
  • Assign role: Project → Editor (or restrict further as needed).
  • Click Done.

Get Your Two Credentials

  • (a) The Key File ("Password"): Open the service account, go to the Keys tab, click Add key → Create new key → JSON, then Create. A `.json` file will download. Store it securely!
  • (b) The Client ID ("Username"): Go to the Details tab and copy the long number labeled **Client ID**.

🛡️ Step 3: Authorize the Service Account in Google Workspace

Navigate to Domain-Wide Delegation

  • In the Google Admin Console, go to: Security → Access and Data Control → API Controls.
  • Scroll down and click Manage Domain Wide Delegation.

Authorize Your Service Account

  • Click Add new.
  • Paste the Client ID from Step 2.
  • In the OAuth Scopes field, paste the full, comma-separated list below.
  • Click Authorize.

📊 Step 4 (Optional): Configure BigQuery for Data Analysis

What is BigQuery?

A cloud-scale database designed for storing and analyzing Google Workspace logs, providing permanent, searchable archives for advanced security analysis and reporting.

⚠️ Workspace Plan Requirement

BigQuery export is available only for Google Workspace **Enterprise editions**. If your organization is on Business Starter/Standard/Plus, this feature may not be available.

How to Enable It

  • Ensure the BigQuery API was enabled in Step 1.
  • In Google Admin Console, go to: Reporting → BigQuery Export.
  • Link your Google Cloud Project ID. Google will create a Dataset Name.
  • You'll need both the Project ID and Dataset Name for the dashboard.

✅ Setup Complete!

At this point, your dashboard backend can:

  • Authenticate using the downloaded .json key file.
  • Fetch user data, MFA status, email settings, and alerts via APIs.
  • (If on an Enterprise plan) Query historical logs via BigQuery for deeper analysis.
